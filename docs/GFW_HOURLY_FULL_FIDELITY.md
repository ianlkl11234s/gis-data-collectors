## Source semantics

- Dataset: `public-global-presence:latest`, with the resolved version pinned in every run.
- Temporal resolution: `HOURLY` UTC.
- Spatial resolution: `HIGH`.
- GFW documents `HIGH` as one hundredth of a degree and documents `lat`/`lon`
  as the center of the grid cell.
- GFW does not document the report grid origin or exact boundary rule. Any polygon
  generated by this collector is therefore an inferred visualization footprint:
  `center +/- 0.005 degree`, not an official GFW boundary.
- Track coordinates remain GFW grid-cell centers, not raw AIS positions.

Official references:

- https://globalfishingwatch.org/our-apis/documentation/docs/v3/4wings/report
- https://globalfishingwatch.org/our-apis/documentation/docs/license-rate-limits

## Full-fidelity definition

For a successful release, all expected spatial request tiles must complete with one
resolved dataset version and no non-zero `nextOffset`. The run must account for every
fetched row through invalid, exact-duplicate, same-vessel-hour conflict, canonical,
eligible-segment, or singleton counters.

The following invariants are mandatory:

- every expected request tile is present in the fetch ledger;
- `sum(grid vessel_count) == canonical_vessel_hour_count` for each hour;
- `published_segment_count == eligible_segment_count`;
- `published_segment_points == eligible_segment_points`;
- `cap_applied == false` and `omitted_by_display_cap == 0`;
- every canonical point belongs to one eligible segment or singleton node;
- every popup/detail member count matches the referenced cell or motion group.

A resource guard may fail the run, but it must never select a subset of features.

## Track rules

- one deterministic canonical point per vessel and UTC hour;
- a gap greater than the configured threshold starts a new segment;
- an implied speed above the configured threshold starts a new segment;
- a segment needs at least two points to become a `LineString`;
- a one-point segment is published as a singleton node, not discarded or converted
  into a fabricated line;
- only linear interpolation between adjacent points in the same segment is allowed.

## Grid visualization contract

Grid polygons use the inferred 0.01-degree footprint and retain the official center as
identity. Frontend hour animation is a cross-fade between two observed frames:

- hour H opacity: `1 - fraction`;
- hour H+1 opacity: `fraction`.

Cell position, count, and vessel membership are not interpolated. If H+1 is missing or
invalid, H stays fully visible.

## Publication and lifecycle

- normalized shards are durable until every required asset is uploaded and verified;
- immutable release assets are uploaded before the root manifest is changed;
- failed/incomplete runs never advance current;
- current and previous immutable releases remain available for rollback;
- cleanup enumerates exact manifest keys and never deletes a broad prefix;
- root manifests use short cache headers; immutable assets use long cache headers;
- raw GFW response bodies are not archived by this contract.

Mini Taiwan Pulse's public use is noncommercial and must display `Powered by Global
Fishing Watch`, dataset/version/date-range metadata, delayed/approximate positioning
language, and applicable downstream attribution. The API token must never enter a
public frontend bundle or asset.
